# AI Interview Challenges

Hands-on engineering interview challenges from **Remote Legal Engineering**, built for working the way engineers work now: with AI.

You're expected to use AI assistants during these challenges. We're less interested in whether you can type code and more interested in what you do with it:

- **Understand** the problem before changing anything.
- **Direct** your tools with the right context.
- **Verify** the result with real evidence.
- **Explain** the trade-offs you made.

## Challenges

| Challenge | Time | What it is |
|---|---|---|
| [Augmented Chess](augmented-chess/) | 1 hour, live | A two-player chess variant in a single HTML file, where each player drafts an "augment" that bends the rules. You'll take it through three short stages, each harder than the last. |

## Getting started

```bash
git clone https://github.com/PrecisionReporters/ai_interview_challenges.git
```

1. Open `augmented-chess/augmented-chess.html` in a current Chrome, Edge or Firefox. There's nothing to install, no build step and no server.
2. Read [`augmented-chess/CANDIDATE_HANDOUT.pdf`](augmented-chess/CANDIDATE_HANDOUT.pdf). It covers the ground rules, setup and the tickets you'll work on.
3. Choose **Practice on one screen** to play both sides locally. Online play is peer-to-peer (WebRTC) and works between two tabs on the same machine.

Your interviewer will walk you through the rest at the start of the session.

## A few notes

- **Use whatever tools you normally use.** That includes any AI assistant, agent or editor.
- **The code is intentionally imperfect.** It works, it has some tech debt, and it has no tests. Leave that as you find it until the interview.
- **Please don't publish solutions**, open pull requests or post write-ups. It keeps the challenge fair for everyone who comes after you.
